# 09 安全与注意事项

本仓库仅供学习、研究和参考。

## 网络规范

使用者应遵守所在学校、单位或网络提供方的管理规定。不要把本项目当作规避网络管理要求的保证工具。

## 计费

不同接入方式、网络策略、账号和时间段可能不同。任何流量统计结果都只作为单次实验观察，不构成长期承诺。

## 私密信息

以下内容禁止提交 GitHub：

- 订阅 URL
- 节点 password
- 登录 Token
- Cookie
- 账号密码
- 私人 API Key
- 带凭据的完整客户端备份

如果要向 AI 提供日志，应先检查是否含上述内容。

## 第三方软件

只从可信来源获取安装包。对下载文件记录版本、来源和 SHA256。仓库暂不重新分发来源或授权不明确的第三方安装包。

## DNS 引导例外

“不要未验证就修改 DNS”不等于“任何 DNS 修改都禁止”。

本仓库明确允许 [01A-DNS引导](01A-DNS引导.md) 中规定的受控流程，前提是：

- Windows 已经获得校园公网 IPv6；
- 物理 IPv6 默认路由存在；
- 问题表现为域名解析 / CrushCloud 登录或接口加载异常；
- 修改前记录当前 DNS；
- 只修改实际物理校园上行；
- 失败后不继续叠加其他网络修改。

当前已验证的 IPv6 DNS 为阿里公共 DNS：

~~~text
2400:3200::1
2400:3200:baba::1
~~~

如果操作系统本身没有 IPv6 地址或默认路由，DNS 引导不适用。

## 自动化安全模型

网络自动化脚本必须 Fail-Closed：

- 能确认环境 → 执行已定义修改
- 不能确认环境 → 不修改
- 离开目标环境 → 恢复项目自己做过的临时修改
