# 08 恢复与卸载

任何安装方案都必须能恢复。

## 当前手工恢复原则

### CrushCloud

- 取消自定义覆写或切回原配置。
- 退出客户端。
- 不需要删除 Windows IPv6。

### Windows 热点

如果某个脚本把热点 MTU 从原值调整为 1400，卸载时必须恢复记录的原值，而不是假设所有电脑原值都是 1500。

### 路由

只删除本项目明确创建并记录的节点 /128 路由。

严禁使用“删除所有 IPv6 路由”的方式卸载。

### SkipAsSource

只恢复 AutoFix 状态文件中记录为由本项目改过的地址。

## 通用卸载器要求

未来 scripts/Uninstall.ps1 必须：

1. 停止本项目计划任务。
2. 读取状态文件。
3. 恢复本项目管理的 MTU。
4. 恢复本项目管理的 SkipAsSource。
5. 删除本项目创建的 /128 路由。
6. 删除本项目任务与状态文件。
7. 不修改其他 VPN/代理客户端。
8. 不执行 Windows 网络重置。
