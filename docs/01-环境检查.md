# 01 安装前环境检查

先检查，后修改。不要跳过本页。

## 基本要求

- Windows 11 为主要测试环境。
- 建议使用有线校园网作为电脑上行。
- 当前校园网必须已经完成基础认证。**如果 Windows 已有校园公网 IPv6 + 物理 IPv6 默认路由，但普通域名或 CrushCloud 登录页打不开，不要把它直接判定为环境失败；先按 [01A-DNS引导](01A-DNS引导.md) 判断是否属于 DNS 引导场景。**
- Windows IPv6 必须保持启用。
- 需要管理员 PowerShell 执行系统级检查。

## 检查命令

管理员 PowerShell：

~~~powershell
Get-NetAdapter | Format-Table ifIndex,Name,InterfaceDescription,Status,LinkSpeed
Get-NetIPAddress -AddressFamily IPv6 | Format-Table InterfaceIndex,InterfaceAlias,IPAddress,PrefixOrigin,SuffixOrigin,AddressState,SkipAsSource
Get-NetRoute -AddressFamily IPv6 -DestinationPrefix "::/0" | Format-Table InterfaceIndex,InterfaceAlias,NextHop,RouteMetric
~~~

## 合格条件

至少确认：

1. 存在已连接的物理有线网卡。
2. 物理网卡获得校园 IPv6 地址。
3. 存在经物理网卡的 IPv6 默认路由。
4. 默认网关通常是 link-local IPv6（fe80::/10）。
5. 当前并非仅依赖代理虚拟网卡才能联网。

## 不要做

- 不要手动写死其他设备的 ifIndex。
- 不要抄别人当前的 DHCPv6 地址。
- 不要删除 ::/0 默认路由。
- 不要把 IPv6 关掉再“试试看”。
- 不要先执行 Windows 网络重置。

如果操作系统层没有校园公网 IPv6 或没有物理 IPv6 默认路由，停止安装并先排查链路/DHCPv6/RA。

如果操作系统层 IPv6 正常，但域名解析或 CrushCloud 登录异常，先看 [01A-DNS引导](01A-DNS引导.md)，不要直接 HOLD。
