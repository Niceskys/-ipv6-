# 05 电脑端验证

配置完成后不要直接进行大流量测试，先分层验证。

## 1. 核心是否运行

~~~powershell
Get-Process crushcloudCore -ErrorAction SilentlyContinue
~~~

## 2. IPv6 地址与默认路由

~~~powershell
Get-NetIPAddress -AddressFamily IPv6 | Format-Table InterfaceIndex,InterfaceAlias,IPAddress,PrefixOrigin,SuffixOrigin,AddressState,SkipAsSource
Get-NetRoute -AddressFamily IPv6 -DestinationPrefix "::/0" | Format-Table InterfaceIndex,InterfaceAlias,NextHop,RouteMetric
~~~

## 3. 观察核心远端连接

~~~powershell
$core = Get-Process crushcloudCore -ErrorAction SilentlyContinue | Select-Object -First 1
if ($core) { Get-NetTCPConnection -OwningProcess $core.Id -ErrorAction SilentlyContinue | Format-Table State,LocalAddress,LocalPort,RemoteAddress,RemotePort }
~~~

重点确认代理外层实际连接使用 IPv6。

## 4. 客户端 UI

GLOBAL、自动选择、故障转移只应看到脚本允许的节点集合。

## 5. 小流量功能测试

先测试普通网页和小文件，不要一上来下载几十 GB。

## 6. 计费观察

任何计费表现都只能作为当前网络环境中的实验现象记录，不能推断为长期规则或对其他账号的保证。

记录测试时间、网络接入方式、客户端版本和测试前后数据，便于复现。
