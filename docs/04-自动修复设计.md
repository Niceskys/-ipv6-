# 04 自动修复设计

当前个人环境中已经验证过 AutoFix v6.1，但原版本包含针对单台电脑逐步调试形成的校园特征。直接复制给其他同学并不安全。

因此仓库暂时只冻结设计规范，通用版脚本完成审计后再发布。

## 通用版必须做到

### 强校园网识别

只在检测到可信校园 IPv6 特征时执行修改。无法确认时 Fail-Closed。

### 自动发现

安装器应自动发现：

- 物理 IPv6 默认路由
- 物理网卡
- 当前 IPv6 前缀
- link-local 网关
- CrushCloud 核心进程
- 实际 IPv6 节点连接
- Windows 移动热点接口

### IPv6 源地址策略

如果同一物理网卡同时存在 DHCPv6 与 Router Advertisement 地址，应先检测实际环境，再决定是否需要调整 SkipAsSource。

严禁写死某个具体 DHCPv6 地址。

### 节点绕行

代理节点自身的外层 IPv6 连接不能再次进入 TUN。脚本应根据核心实际连接动态维护节点 /128 物理路由。

### 热点 MTU

移动热点存在时可以管理热点接口 MTU；必须记录原值并可恢复。

不能把物理以太网 MTU 一起修改。

### 状态所有权

AutoFix 只能恢复自己曾经修改过的对象：

- 自己创建的路由
- 自己调整过的 SkipAsSource
- 自己调整过的热点 MTU

不得“顺便清理”其他软件或系统配置。
