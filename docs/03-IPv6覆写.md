# 03 IPv6 覆写

当前稳定脚本位于：

[overrides/campus-ipv6.js](../overrides/campus-ipv6.js)

## 当前策略

脚本会：

- 开启配置中的 IPv6 支持。
- 保留校园认证与 Windows 热点局域网的 TUN 排除。
- 只保留名称匹配“香港 V6”的节点。
- 自动选择与故障转移只在这些香港 V6 节点中运行。
- 对节点设置 IPv6 限制字段，避免域名节点意外使用 IPv4。
- 使用大陆 generate_204 地址做健康检查。
- 如果找不到任何合格香港 V6 节点，则 Fail-Closed，不回退到 V4。

## 使用方法

在 CrushCloud：

~~~text
自定义覆写
→ 脚本
→ 新建脚本
→ 粘贴 campus-ipv6.js
→ 保存
→ 选中该脚本
→ 重启服务
~~~

## 成功后的 UI 特征

GLOBAL / 自动选择 / 故障转移应只出现目标香港 V6 节点，不应出现：

- 实验性 V4
- 日本/新加坡/美国/韩国/澳门等其他地区
- 剩余流量、到期时间等信息节点

如果 UI 未立即刷新，先重启服务再检查。

## 注意

脚本依赖节点命名规则。如果第三方订阅改名，可能导致一个节点都匹配不到，此时应停止使用并重新审计脚本，而不是放宽到 V4。
