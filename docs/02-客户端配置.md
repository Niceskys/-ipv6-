# 02 客户端配置

当前测试客户端为 CrushCloud。具体版本和第三方服务可能发生变化，因此本仓库不直接保存私人订阅。

## 原则

- 客户端使用自己的账号和订阅。
- 不把他人的订阅链接、密码或 Token 写入仓库。
- 首次安装后先确认普通节点可以正常连接，再做 IPv6 覆写。
- 如果同时安装其他代理客户端，不要让两个客户端同时接管 TUN、系统代理或 DNS。

## 建议流程

1. 安装来源明确的客户端。
2. 登录自己的账号。
3. 导入自己的订阅。
4. 确认能看到节点和代理组。
5. 暂时不要开启自定义覆写。
6. 记录当前配置，确保可回退。
7. 再进入 [03-IPv6覆写](03-IPv6覆写.md)。

## 多客户端共存

如果同时使用其他客户端，例如 v2rayN：

- CrushCloud 用于本项目实验时，其他客户端应清除系统代理并退出。
- 其他客户端使用时，CrushCloud 应退出。
- 不建议两个程序同时开启 TUN。
