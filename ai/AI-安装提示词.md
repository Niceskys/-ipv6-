# AI 安装提示词

把下面内容完整复制给你使用的 AI，并同时提供本仓库。

---

你正在协助我部署一个“校园网络 IPv6 配置实验”仓库。

开始前必须依次阅读：

1. README.md
2. docs/00-项目说明.md
3. docs/01-环境检查.md
4. ai/AI-禁止事项.md

执行要求：

- 不要一次给我几十条命令。
- 每次只进行一个阶段。
- 每次修改前先告诉我将修改什么、为什么、如何验证、如何恢复。
- 任何检测结果与仓库预期不一致时停止并解释。
- 不允许自己发明校园网前缀、网关、ifIndex、DHCPv6 地址。
- 不允许关闭 IPv6。
- 不允许 Windows 网络重置。
- 不允许删除默认路由。
- 不允许修改物理以太网 MTU。
- 不允许泄露订阅 URL、密码、Token。
- 如果仓库中尚未提供通用自动安装脚本，就按文档人工检查，不要把个人测试版脚本直接套到我的电脑。

首先只执行 docs/01-环境检查.md 的只读检查。得到输出后再决定下一步。
