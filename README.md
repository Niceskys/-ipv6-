# 校园网络 IPv6 配置实验

> 仅供学习、研究和参考。

本仓库记录 Windows 校园网络环境下的 IPv6、路由选择、代理客户端、移动热点与故障排查方法。不同宿舍、网卡、系统版本和网络策略可能存在差异，使用前请先阅读文档并自行确认环境。

## 快速入口

如果你已经能正常使用 CrushCloud，并且当前就在校园有线网络：

1. 阅读 [安装前环境检查](docs/01-环境检查.md)。
2. 按 [客户端配置](docs/02-客户端配置.md) 完成自己的账号/订阅。
3. 导入 [IPv6 覆写](overrides/campus-ipv6.js)。
4. 进入 `scripts`，右键/双击 `Run-Install.cmd`，按提示完成通用 Helper 安装。
5. 运行 `Run-Check.cmd`，确认没有 FAIL。
6. 需要手机热点时再阅读 [手机热点与 NekoBox](docs/06-手机热点与NekoBox.md)。

不会操作时，可把整个仓库交给国内 AI，并让它先阅读 [AI 安装提示词](ai/AI-安装提示词.md) 和 [AI 禁止事项](ai/AI-禁止事项.md)。

## 使用原则

1. 先检查环境，再修改配置。
2. 一次只改一个变量，保留回退路径。
3. 不写死他人的网卡编号、DHCPv6 地址或临时地址。
4. 不执行 Windows“网络重置”作为常规排障手段。
5. 不禁用 IPv6，不删除系统默认路由，不修改物理网卡 MTU。
6. 任何自动化修改都应可恢复，并且只恢复本项目自己做过的修改。
7. 不提交订阅地址、密码、Token、账号等私密信息。

## scripts 当前状态

v0.2.0 已加入第一版通用化脚本：

- `Install.ps1`：安装前强校验、生成本机配置并注册计划任务。
- `CampusNetworkHelper.ps1`：Fail-Closed 的长期辅助进程。
- `Check.ps1`：只读体检。
- `Uninstall.ps1`：按状态文件恢复本项目自己做过的修改。
- `Collect-Diagnostics.ps1`：生成不读取订阅/密码/Token 的诊断报告。
- `Run-*.cmd`：给不熟悉 PowerShell 的用户使用。

**当前通用脚本仍标记为测试版。** 已完成静态安全审计，但尚未在第二台完全独立的电脑上完成端到端复测。第一次给同学安装时，建议全程保留 `Check.ps1` 输出并按文档逐步确认。
